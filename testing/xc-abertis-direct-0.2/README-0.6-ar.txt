XC Abertis Native 0.6 — نسخة تجريبية مستقلة

واجهة إنجليزية جديدة، 53 قناة محفوظة، تحديث ملف المفاتيح المختار، بحث في تغذيات
هسباسات المعروفة وتشخيص القفل والإشارة وتدفق البيانات. يعمل المحرك الجديد من
مصدر C مكتوب للمشروع؛ لا تتضمن الحزمة محرّك EX أو ملفات بايثون أو صورًا منه.
بيانات القنوات والترددات مرجع تقني من القائمة العاملة التي وفرها المستخدم.

مسار العمل:
حجز التيونر عبر Enigma2 -> demux المحجوز -> XC TS/T2-MI -> HTTP محلي
127.0.0.1:9779 -> مشغل Enigma2/XC القياسي. لا يكتب المحرك مصادر demux العامة،
ولا يغير إعدادات التيونر أو إعدادات OSCam أو يستبدل مشغل XC.

من الإضافات افتح XC Abertis:
الأزرق Update keys: تحديث سجلات Abertis فقط مع نسخة رجوع من الملف السابق.
الأخضر Enable / refresh: تفعيل الخدمة وإضافة باقة XC Abertis.
الأصفر Search channels: البحث على هسباسات المهيأ في إعدادات التيونر.
MENU أو Diagnostics: عرض القفل والإشارة والتردد والأخطاء الفعلية.
الأحمر أثناء البحث: إلغاء آمن وإعادة القناة السابقة؛ في الصفحة الرئيسية: إغلاق.

المصدر الافتراضي للتحديث هو المصدر العام الذي ظهر في الإضافة المرجعية.
يمكن تخصيصه في /etc/xc-abertis-direct/key-urls أو اختيار ملف موجود من الواجهة.
لا تُثبت مفاتيح فعلية داخل الحزمة ولا تتغير ملفات الاشتراك الأخرى.

حالة التحقق:
اجتازت اختبارات محلية ببث صناعي: TS داخل TS، CSA بقيمة اختبار، T2-MI NM/HEM،
فقد حزمة، CRC غير صالح، ملف مفاتيح خاطئ، اكتشاف البرامج وإعدادات MIS/PLS.
اختُبر حفظ القنوات والنسخ الاحتياطية والتحديث الذري وإلغاء طلبات التيونر برمجيًا.
البناء ARM64؛ فحص الاعتماديات يشير إلى glibc 2.34 أو أحدث. لم يتوفر اتصال
بالرسيفر أثناء إتمام هذه الحزمة، ولم تُثبت هذه النسخة عليه.
لا يوجد حتى الآن إثبات تشغيل RF فعلي على هسباسات؛ لا توزع كإصدار مستقر.

الحدود الحالية:
البحث في التغذيات المعروفة فقط. T2-MI TS مع NM/HEM دون ISSY/NPD؛ هذه الأنماط
الإضافية ترفض برسالة تشخيص. اختيار أول data PLP افتراضيًا. دعم PES الأساسي
لا يشمل رأس PES مجزأً بين حزم. أنواع غير مثبتة على القمر تحتاج عينة للاختبار.
الإشارة في شريط معلومات قناة HTTP قد لا تظهر؛ Diagnostics يعرض تيونر التغذية.

الترخيص:
كود XC Python تحت MIT، المحرك C تحت GPL-2.0-or-later. مكتبة libdvbcsa عامة
مبنية من مصدرها، مع تراخيصها الأصلية ومصدرها الكامل في أرشيف الإصدار.
